# Bundled fonts

`Phosphor.ttf` is the regular weight of [Phosphor Icons](https://phosphoricons.com)
(MIT License, Copyright (c) 2023 Phosphor Icons), as packaged by
[egui-phosphor](https://github.com/amPerl/egui-phosphor) 0.14.0
(MIT OR Apache-2.0, see `LICENSE-Phosphor-egui-MIT`). It is bundled directly
because egui-phosphor does not yet support egui 0.37.
